# Store Project

## 📖 Description
**DjouneStore Online** est une application web de commerce électronique qui permet aux utilisateurs d’acheter des accessoires variés directement en ligne.  
Les fonctionnalités principales incluent :
- 🛒 **Achat de produits** en ligne.
- 💳 **Paiement sécurisé** par carte de crédit ou via MonCash.
- 🚚 **Livraison rapide** dans la ville où se trouve le client.

Ce projet vise à offrir une expérience simple, moderne et efficace pour la vente et la gestion d’accessoires en ligne.

## 🛠️ Technologies
- Java / Spring Boot
- Hibernate / JPA
- MySQL (Aiven)
- Render (déploiement)
